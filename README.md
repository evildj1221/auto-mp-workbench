# 自动化公众号工作台 · Auto MP Workbench

> 本地优先的开源内容生产工作台：选题 → 写稿 → 质量门禁 → 排版 → 配图 →
> 公众号草稿箱 → 数据复盘，全流程可对话驱动，也可手动精细控制。
> 为情感/治愈/成长类文字创作者设计，支持多账号档案（风格/红线/视觉随档案走）。

## 三分钟看到它能干什么（零密钥）

```
git clone <仓库地址>
cd <项目目录>
pip install -r requirements.txt
python scripts/demo_render.py --open
```

用规则排版引擎现场渲染一篇虚构账号「晚风信箱」的样稿（20/20 校验全过），
浏览器直接看到可粘贴进公众号编辑器的成品排版。**不需要任何 API key。**

## 跑起来（完整工作台）

```
# 1) 后端依赖
pip install -r requirements.txt        # Python 3.12+

# 2) 前端构建（页面资源，必做）
cd frontend && npm install && npm run build && cd ..

# 3) 启动（浏览器访问 http://127.0.0.1:8765）
python run_workbench.py
```

配置自己的账号：`cp .env.example .env` 填入 LLM key 即可开始生成选题/文稿；
生图与微信推送为可选能力，各配各的 key（详见 `.env.example` 注释）。
**微信推送需先在公众平台配置 IP 白名单**——完整步骤与「IP 会变动」的提醒见
`docs/rewrite/07-微信发布配置指南.md`。

## 这是什么

| 能力 | 说明 |
|---|---|
| 对话工作台 | 「编辑部」拟人角色接单：说「生成一批今天的候选」→ 确认卡 → 真干活；手动面板与对话双通道互通 |
| 选题引擎 | 时节/热榜/灵感库多源注入 + 句式家族配额 + 题材反疲劳 + Top5 跨家族选取 |
| 写稿与门禁 | 大纲/写稿/标题方案 + 红线/字数/相似度三层质量门禁 |
| 排版引擎 | 组件化标记语法 → 全内联 HTML + 20 项确定性校验；主题化（换主题=换账号品牌） |
| 配图 | 视觉规范驱动的头图生成（调性判定/模板库/风格参考图），失败优雅降级 |
| 发布 | 公众号草稿箱一键推送（含封面/头图换装）、IP 白名单体检器 |
| 复盘学习 | 发布数据回流 → 偏好校准（带探索配额，防越学越窄） |

## 这不是什么

- 不是托管 SaaS——全部数据在你本机（`~/.<app>/` 与项目 data/），零遥测
- 不是爬虫工具——热榜聚合只用公开接口，内置采集器不含封闭平台爬取
- 不是全自动发稿机——关键节点（选题、发布）保留人工关卡
