# 07 · 微信发布配置指南（草稿箱推送 + IP 白名单）

> 适用：想用本工作台把排版好的文稿一键推到公众号**草稿箱**的用户。
> 不推送的用户可完全跳过本节，其余功能不受影响。

## 一、前置条件

- 已认证的**订阅号或服务号**（草稿箱接口要求认证号）
- 你的电脑能正常上网（推送走公网出口 IP）

## 二、配置三步（约 5 分钟）

### 步骤 1：拿 AppID / AppSecret
1. 登录 mp.weixin.qq.com → **设置与开发 → 基本配置**
2. 复制 **AppID**；AppSecret 若从未记录过，点【重置】→ 管理员微信扫码 →
   **立即复制新值（只显示这一次！）**
3. 写入 `.env`：`WECHAT_APPID=wx…` / `WECHAT_APPSECRET=…`

### 步骤 2：设置 IP 白名单（**关键，漏了这步必失败**）
1. 同一页面找到 **IP 白名单** → 【配置】/【修改】
2. 查你当前的公网出口 IP（任选其一）：
   - 工作台「设置 → 公众号出口 IP」卡片直接显示并可一键复制
   - 或命令行：`python scripts/wechat_doctor.py`（第一步就打印当前 IP）
   - 或浏览器打开 ip.sb
3. 把该 IP 加进白名单 → 保存（管理员扫码确认）

### 步骤 3：体检验证
```
python scripts/wechat_doctor.py
```
三步全 PASS（IP / token / 上传）即可在导出页点「写入草稿箱」。

## 三、⚠️ IP 会变动——长期提醒

**家用/宿舍宽带的公网 IP 是运营商动态分配的，重启光猫/路由器、或隔几天
自动重拨，IP 就会变。** 白名单只认 IP，变了以后推送立刻报 `40164: invalid ip`。

应对方式：
1. **每次推送前跑一次** `python scripts/wechat_doctor.py`——第一行就是当前
   IP，跟白名单对不上就去后台补一条（把新旧 IP 都留在白名单里也无妨）；
2. 工作台设置页有「公众号出口 IP」卡片，状态三态直观（✓在白名单 / ✗不在），
   推送前瞄一眼即可；
3. 若想要**一劳永逸**：把工作台部署到有固定公网 IP 的云服务器上，或用带
   固定出口的代理（成本约 ¥50-100/年），白名单只需配置一次。

## 四、常见报错对照

| 报错 | 含义 | 处理 |
|---|---|---|
| 40125 invalid appsecret | AppSecret 不对 | 后台重置 → 更新 .env |
| 40164 invalid ip | 当前 IP 不在白名单 | 把当前 IP 加入白名单（见上节） |
| 40013 invalid appid | AppID 不对 | 核对 .env 的 WECHAT_APPID |
| 47001 data format error（draft/update） | 微信接口自身限制 | 用「删旧建新」策略（系统内置） |

## 五、隐私说明

AppSecret 只存在你本机的 `.env`（git 已忽略，绝不入库）。本项目零遥测，
推送直接从你的电脑到微信服务器，无中间商。
