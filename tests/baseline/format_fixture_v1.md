# 那封信，是四年前的我自己写来的

你好呀，见字如面。

今天想跟你聊聊一封信的事。不是电子邮件，不是微信消息，是一封真的、贴着邮票、盖着邮戳的信。信封上的字迹有点歪，收件人是我，寄件人也是我。落款日期是四年前的六月。

你猜到了，毕业季嘛，我收到了那封四年前写给自己的信。

说实话，刚拿到的时候，我愣了好一会儿。四年太长了，长到我已经忘了自己还做过这件事。我捏着那个信封，牛皮纸的，边角有点毛了，像被谁翻过很多次。我翻到背面，看见一行小字：“如果你忘了，就看看里面的照片。”

我拆开的时候，手有点抖。里面掉出一张照片，是宿舍楼下的那棵老槐树。四年前的六月，我大概就是坐在那棵树下，晒着太阳，一笔一笔地写这封信的。

信不长，字也写得潦草。开头第一句是：“嘿，四年后的我，你还好吗？”

我坐在客厅的沙发上，把这句话读了好几遍。你还好吗。这四个字，我好像很久没有问过自己了。每天醒来就是打开手机，看消息，回消息，赶地铁，开会，改方案，再回消息。日子像一条匀速流淌的河，我泡在里面，不觉得冷，也不觉得热，只是湿着。

信里写了很多那时候的烦恼。比如毕业论文的导师又改了题目，比如宿舍楼下的猫最近不怎么出来了，比如隔壁床的姑娘保研了，自己还在纠结要不要去考那个没什么把握的试。四年前的我，在信里絮絮叨叨地说着这些事，最后写了一句：“不知道你现在过得好不好。如果不好，也没关系，反正我在这里，先替你扛着。”

看到这句，我鼻子酸了一下。那时候的我，什么都不知道，不知道四年后自己会在哪个城市，做着什么样的工作，身边站着什么样的人。可那个傻乎乎的我，居然在信里说，要替我扛着。

我接着往下读。信里夹了一张超市小票，是四年前某天买的东西：一盒牛奶，两包方便面，一根火腿肠。我盯着那张小票看了很久，想不起来那天为什么买这些。可能是赶论文的深夜，可能是懒得下楼吃饭的傍晚。那些具体到琐碎的日子，像被水泡过的字迹，模糊了，但还在。

我把信放在膝盖上，窗外的天已经暗下来了。客厅没开灯，只有手机屏幕的光。我忽然想起四年前写这封信的那个下午，阳光很好，我坐在老槐树底下，旁边放着一瓶没喝完的矿泉水。我写一会儿，停一会儿，看看路过的人，再看看树上的叶子。那时候时间很慢，慢到我有空去想象四年后的自己。

可现在呢，我连给自己写封信的时间都没有了。不是真的没有，是总觉得不着急，总觉得以后再说。可那个“以后”，好像一直没来。

:::quote
我们总以为来日方长，其实连给自己写封信，都拖成了遥遥无期。
:::

我拿起手机，想给四年前的自己回一封信。可我知道，寄不到了。那个坐在槐树下的姑娘，已经走远了。她替我扛过了那些熬夜赶论文的日子，扛过了毕业的兵荒马乱，扛过了刚工作时的不知所措。她扛完了，就悄悄退场了，连句再见都没说。

我忽然有点想她。不是想念那时候的日子，是想念那个愿意花一个下午，认认真真给自己写信的自己。那时候的我，对未来一无所知，却愿意把那些琐碎的、笨拙的、甚至有点傻气的念头，一笔一画地留下来。

:::image 傍晚的窗台，一封信摊开，旁边放着一杯凉透的茶
:::

我把信重新折好，放回信封里。没有放回抽屉，就放在茶几上。我想，也许从今天起，我可以试着重新给自己写信。不用等四年，不用等什么特别的日子。就今天，就现在，写几句话给明年的自己。

不是要交代什么，也不是要叮嘱什么。就是想告诉她，今天傍晚的云很好看，楼下便利店的关东煮还是那个味道，我最近学会了一道新菜，虽然卖相一般，但味道还行。这些小事，不写下来，过几天就忘了。可它们是我真实活过的痕迹。

四年前的我，用一封信告诉我：那些你以为过不去的，都过去了。那些你担心的，大多没有发生。而你自己，比想象中要能扛。

我想，这大概就是写信的意义吧。不是写给谁看，是写给时间，写给那个正在赶路的自己。告诉她，别急，慢慢走，路边的花开了又谢，谢了又开，你总会走到你想去的地方。

:::quote
慢一点没关系，只要还在走，就总会到的。
:::

:::action
今晚睡前，花三分钟，给一年后的自己写三句话。不用多，三句就好。
:::

信读完了，我把它放回信封里。茶几上的茶已经凉了，我起身去烧水。窗外的路灯亮起来了，楼下的树影影绰绰的，像四年前那棵老槐树的影子。

其实也没什么特别的。就是忽然觉得，日子虽然过得快，但有些东西，还是可以慢下来的。比如给自己写封信，比如读一封四年前的信，比如在这样一个普通的夜晚，想起那个坐在槐树下写信的自己。

她挺好的。我也挺好的。我们都挺好的。
